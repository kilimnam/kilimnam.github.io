# 남길임 교수 홈페이지

정적 HTML 사이트입니다. 서버나 빌드 도구 없이 `index.html`을 브라우저로 열면 바로 동작합니다.

## 파일 구성

```
index.html               소개(연락처 포함) · 연구 분야 · 경력 · 학력
publications.html        연구업적 — 학술지(J) · 학술대회(C) · 저역서(B)
projects.html            연구사업 — 목록 · 연도별 그래프
assets/css/style.css     전체 스타일. 맨 위 :root 변수만 고치면 색이 한 번에 바뀝니다.
assets/js/data.js        모든 목록 데이터 (수정은 여기서)
assets/js/site.js        목록 렌더링, 검색/필터, 다크모드 전환
assets/img/portrait.png  프로필 사진
```

## 여는 방법

`index.html`을 **파일 탐색기에서 더블클릭**해서 브라우저로 여세요.
편집기의 미리보기 창으로 열면 `assets/` 폴더의 CSS·JS를 못 읽어서 글자만 나옵니다.
파일이 깨진 게 아니라 미리보기의 한계입니다.

## 데이터

`assets/js/data.js` 안에 네 개의 목록이 있습니다.

| 변수 | 내용 | 갈래 표시 |
|---|---|---|
| `window.PUBLICATIONS` | 학술지 논문 119건 | J (남색) |
| `window.CONFERENCES` | 학술대회 발표 48건 | C (보라) |
| `window.BOOKS` | 저역서 23종 | B (분홍) |
| `window.PROJECTS` | 연구사업 66건 | — |

각 항목에는 `intl: true/false`가 있어 **국외**(주황) · **국내**(초록) 꼬리표가 붙습니다.
항목을 추가하려면 해당 배열에 한 줄 더 쓰면 됩니다. 연도별 묶음과 정렬은 자동입니다.

### 원본

`개인이력서.xls`의 다음 항목에서 뽑았습니다.

- `5. 논문게재` → J
- `10. 학술활동` → C
- `7. 저역서` → B
- `6. 연구비수혜` → 연구사업

연구비 금액은 웹 공개 대상이 아니므로 넣지 않았습니다.
다년과제는 연차별로 나뉘어 등록된 것을 기간을 이어 한 건으로 합쳤습니다(125건 → 66건).
과제명 앞의 `[SM]`, `[이관]` 같은 행정용 표기와 끝의 `(1/4)` 연차 표기는 지웠습니다.

## 자주 하는 수정

**사진 교체** — `assets/img/portrait.png`를 덮어쓰면 됩니다. 비율이 크게 다르면
`index.html`의 `<img class="portrait" ...>`에 있는 `width`·`height`도 함께 고쳐 주세요.

**연구 분야 · 경력 · 학력** — `index.html`의 `<ul class="bullets">` 안을 직접 편집하세요.

**저자 이름 강조** — `assets/js/site.js` 맨 위 `ME` 배열에 표기 변형을 넣으면 됩니다.
현재 `남길임`, `Kilim Nam`, `N. Kilim`, `Nam K.`, `Nam`, `Kilim`을 하늘색으로 칠합니다.

**색 바꾸기** — `assets/css/style.css` 맨 위 `:root`의 `--accent`가 포인트 색입니다.
어두운 화면용 값은 그 아래 `[data-theme="dark"]` 블록에 있습니다.
기본은 항상 흰 바탕이고, 오른쪽 위 버튼을 눌러야 어두운 화면으로 바뀝니다.

## 남은 확인 사항

- 학술대회 발표 48건 중 **27건에 개최 연도가 없습니다**. 원본 이력서의 개최일자 칸이
  비어 있어 목록 맨 아래 '연도 미상'으로 모아 두었습니다.

## 웹에 올릴 때

폴더 전체를 그대로 올리면 됩니다. 빌드 과정이 없습니다.
`개인이력서.xls`와 `남길임 교수님 논문 및 사업 업적 정리.xlsx`는 자료 원본일 뿐
사이트에서 링크하지 않으므로 업로드에서 빼셔도 됩니다.
