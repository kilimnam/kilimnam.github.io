남길임 교수 홈페이지 — 편집 안내
====================================

이 폴더를 통째로 웹 서버에 올리면 그대로 홈페이지가 됩니다.
빌드 도구나 서버 프로그램이 필요 없습니다.
index.html 을 더블클릭하면 브라우저에서 바로 확인할 수 있습니다.

  ※ 코드 편집기의 미리보기 창으로 열면 assets 폴더를 못 읽어
     글자만 나옵니다. 반드시 파일 탐색기에서 더블클릭해서 여세요.


폴더 구성
------------------------------------
index.html                소개 (한국어 / English 전환)
publications.html         연구업적 — 학술지 · 학술대회 · 저역서
projects.html             연구사업

assets/css/style.css      색, 글꼴, 여백 등 모든 디자인
assets/js/data.js         목록 데이터 (논문·저역서·연구사업)
assets/js/site.js         목록을 화면에 그리고 검색·필터를 처리
assets/img/portrait.png   프로필 사진


1. 목록에 항목 추가하기  →  assets/js/data.js
------------------------------------
파일 안에 네 개의 목록이 있습니다.

  window.PUBLICATIONS   학술지 논문   (화면에 J 표시)
  window.CONFERENCES    학술대회 발표 (화면에 C 표시)
  window.BOOKS          저역서        (화면에 B 표시)
  window.PROJECTS       연구사업

기존 줄을 복사해서 값만 바꾸는 것이 가장 안전합니다.

  학술지 논문 예시
  { id: "J0", year: 2027, ym: "2027.03", title: "논문 제목",
    titleAlt: "English Title", venue: "한글", authors: "남길임, 홍길동",
    intl: false, vol: "88", no: "1", pages: "1-30" },

  intl      국외면 true, 국내면 false  (초록/주황 꼬리표가 여기서 정해집니다)
  titleAlt  영문 병기 제목. 없으면 ""
  id        서로 겹치지만 않으면 아무 값이나 괜찮습니다
  year      숫자, 따옴표 없이

연도별 묶음과 정렬, 개수 세기는 자동으로 됩니다.

  ★ 주의 ★
  쉼표(,)나 따옴표(")가 하나만 빠져도 목록 전체가 안 나옵니다.
  고친 뒤 화면이 비어 있으면 방금 고친 줄을 다시 보세요.
  제목 안에 큰따옴표를 쓰려면 \" 로 적어야 합니다.


2. 소개·연구 분야·경력·학력 고치기  →  index.html
------------------------------------
해당 부분의 <li> 줄을 직접 고치면 됩니다.

한국어와 영어가 나란히 들어 있습니다.

  <span class="ko">한국어 문장</span>
  <span class="en">English sentence</span>

class="ko" 는 한국어 화면에서, class="en" 은 영어 화면에서만 보입니다.
둘 다 고쳐야 양쪽 화면이 맞습니다.

기본은 영어로 열리고, 오른쪽 위 버튼으로 전환합니다.
기본을 한국어로 바꾸려면 index.html 첫 부분의 "en" 두 군데를 "ko" 로 고치세요.


3. 사진 바꾸기
------------------------------------
assets/img/portrait.png 를 새 파일로 덮어쓰면 됩니다.
가로세로 비율이 많이 다르면 index.html 의
<img class="portrait" ...> 안에 있는 width, height 숫자도 함께 고쳐 주세요.


4. 색과 글꼴 바꾸기  →  assets/css/style.css
------------------------------------
파일 맨 위 :root { } 안의 값만 고치면 사이트 전체에 반영됩니다.

  --accent   포인트 색 (링크, 강조)
  --bg       바탕색
  --ink      본문 글자색
  --font     글꼴

어두운 화면용 색은 그 아래 [data-theme="dark"] 블록에 있습니다.
기본은 항상 흰 바탕이고, 오른쪽 위 버튼을 눌러야 어두운 화면이 됩니다.


5. 자동으로 처리되는 것들
------------------------------------
· 저자 목록에서 '남길임', 'Kilim Nam', 'N. Kilim' 등은 하늘색으로 강조됩니다.
  표기를 추가하려면 assets/js/site.js 맨 위 ME 배열에 넣으세요.
· 괄호 앞뒤는 자동으로 한 칸 띄웁니다.
  Linguistics(3rd edition) → Linguistics (3rd edition)
· 연구사업의 종료일이 오늘보다 뒤면 '진행 중' 표시가 붙습니다.


6. 웹에 올리기
------------------------------------
GitHub Pages 를 쓰는 경우, 파일을 고친 뒤 아래 명령 한 줄이면 반영됩니다.

  git add -A
  git commit -m "내용 수정"
  git push

1~2분 뒤 사이트에 적용됩니다.
바뀐 것이 안 보이면 브라우저에서 Ctrl+F5 로 새로고침하세요.
